Anthropic or OpenAI API format, hosted officially, by another provider, through a gateway, or locally.

This provider fills the **model.reasoning**, **model.fast**, **model.exploit** slot. Configure it in
**Settings → Providers**, or during first-run setup.

## Settings

| Key | Field | Type | Required | Notes |
|---|---|---|---|---|
| `apiFormat` | API format | one of: `openai`, `anthropic` | Yes | Choose the request/response shape the endpoint accepts. This is independent of who hosts it. Default: `openai`. |
| `endpointMode` | Endpoint | one of: `official`, `custom` | Yes | Official uses api.openai.com or api.anthropic.com. Custom supports gateways, other providers, and local inference. Default: `official`. |
| `baseUrl` | Custom base URL | URL | No | The API root, usually ending at /v1. HTTP is supported for private/local deployments. Shown when **endpointMode** is `custom`. |
| `model` | Model ID | text | Yes | — |
| `pricingModel` | Pricing model ID | text | No | Only needed when Model ID is a gateway alias. Enter the upstream billable model from the bundled aggregate, for example anthropic/claude-sonnet-5. |
| `apiKey` | API key | secret reference | No | Optional secret reference: env:NAME or file:/run/secrets/x. Leave blank for a keyless local endpoint. |
| `reasoningStyle` | Thinking mode style | one of: `none`, `openai_effort`, `anthropic_thinking`, `qwen_enable_thinking` | No | How this endpoint expresses reasoning/thinking. none = the model has no toggle. Default: `none`. |
| `defaultReasoning` | Default thinking level | one of: `off`, `low`, `medium`, `high` | No | Recommended: high for the reasoning slot, off for the fast slot. Default: `off`. |
| `reasoningBudgetTokens` | Thinking token budget (high) | number | No | Budget for "high" effort on Anthropic-style thinking. Defaults to 24576. Shown when **reasoningStyle** is `anthropic_thinking`. |
| `extraBody` | Extra request JSON | text | No | Optional JSON object merged into every request body (provider-specific params). |
| `inputUsdPerM` | Input $ / 1M tokens | number | No | Optional. Leave all three blank to use the bundled pricing aggregate. |
| `cachedInputUsdPerM` | Cached input $ / 1M tokens | number | No | Required with the other overrides. Use the input rate when the provider has no cache discount. |
| `outputUsdPerM` | Output $ / 1M tokens | number | No | Required with the other overrides. Local inference can use 0 for all three. |

<Note>
  One field is a secret (`apiKey`). Secrets are never stored in the database: you give a reference and the value is resolved when it is used. `env:NAME` reads a process environment variable; `file:/run/secrets/name` reads a mounted secret file.
</Note>
