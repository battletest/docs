One stateless gateway for GitHub, GitLab, Bitbucket Cloud, Bitbucket Data Center, Azure DevOps, Gitea, Gogs, Gitee, and Harness Code. BattleTest owns authentication; the enterprise supplies endpoint and secret references.

This provider fills the **scm** slot. Configure it in
**Settings → Providers**, or during first-run setup.

## Settings

| Key | Field | Type | Required | Notes |
|---|---|---|---|---|
| `providerId` | SCM provider | one of: `github`, `gitlab`, `bitbucket`, `bitbucket_server`, `azure`, `gitea`, `gogs`, `gitee`, `harness` | Yes | Default: `github`. |
| `endpoint` | API endpoint | URL | No | Leave blank for the provider’s official endpoint. Required for self-hosted providers and custom domains. |
| `webBase` | Web endpoint | URL | No | Browser-facing base URL used for change links. Leave blank when it matches the official provider. |
| `authMode` | Authentication | one of: `github_app`, `bearer`, `basic`, `private_token`, `header`, `none` | Yes | Default: `bearer`. |
| `appId` | GitHub App ID | text | No | Shown when **authMode** is `github_app`. |
| `installationId` | GitHub App installation ID | number | No | Shown when **authMode** is `github_app`. |
| `username` | Username | text | No | Shown when **authMode** is `basic`. |
| `credential` | Credential | secret reference | No | Token, password, or GitHub App private-key reference (env:NAME / file:/path). Leave blank only for anonymous local SCM. |
| `headerName` | Header name | text | No | Shown when **authMode** is `header`. |
| `scheme` | Header scheme | text | No | Optional prefix such as Bearer. Shown when **authMode** is `header`. |
| `owner` | Account / organisation | text | No | Used by Azure DevOps drivers. |
| `project` | Project | text | No | Used by Azure DevOps and Harness. |
| `account` | Harness account | text | No | — |
| `organization` | Harness organisation | text | No | — |
| `botLogin` | Integration bot login | text | No | Used only to identify and supersede this integration’s own reviews. GitHub Apps default to GITHUB_APP_SLUG[bot]. |
| `probeRepo` | Connection-test repository | text | No | Optional provider-native repository path, for example owner/repo. Required when testing anonymous access. |
| `orgId` | BattleTest organisation | text | Yes | Runs received through this connection are attributed to this BattleTest organisation. |
| `webhookSecret` | Webhook secret | secret reference | No | — |

<Note>
  2 fields are secrets (`credential`, `webhookSecret`). Secrets are never stored in the database: you give a reference and the value is resolved when it is used. `env:NAME` reads a process environment variable; `file:/run/secrets/name` reads a mounted secret file.
</Note>

## What the connection test checks

Saving runs a live test against the credentials you supplied. Every check below is evaluated against the real service, not inferred from the configuration.

| Check | Outcome |
|---|---|
| Reach the internal SCM gateway | Must pass |
| Authenticate to the selected SCM provider | Must pass |
