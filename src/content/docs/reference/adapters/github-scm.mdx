A GitHub App connection to github.com or a self-hosted GHES instance.

This provider fills the **scm** slot. Configure it in
**Settings → Providers**, or during first-run setup.

## Settings

| Key | Field | Type | Required | Notes |
|---|---|---|---|---|
| `host` | GitHub host | text | No | GHES hostname, e.g. github.yourco.com. Blank = github.com. Derives api/web/uploads/graphql. |
| `appId` | GitHub App ID | text | Yes | — |
| `privateKey` | App private key | secret or reference | Yes | PEM private key. Secret reference (env:NAME / file:/path). |
| `webhookSecret` | Webhook secret | secret or reference | No | HMAC secret for this instance’s inbound webhooks. |
| `clientId` | OAuth client ID | text | No | — |
| `clientSecret` | OAuth client secret | secret or reference | No | — |

<Note>
  3 fields are secrets (`privateKey`, `webhookSecret`, `clientSecret`). Pasted secrets are encrypted before storage. You can also supply a reference resolved when it is used. `env:NAME` reads a process environment variable; `file:/run/secrets/name` reads a mounted secret file.
</Note>

## What the connection test checks

Saving runs a live test against the credentials you supplied. Every check below is evaluated against the real service, not inferred from the configuration.

| Check | Outcome |
|---|---|
| Authenticate as the GitHub App (App-JWT accepted) | Must pass |
| Resolve the App identity (GET /app) | Must pass |

_Adapter id: `github-scm`._
