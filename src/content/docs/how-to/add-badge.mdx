---
title: "Add the Battletested! badge"
description: "Show that your project uses BattleTest PR security reviews."
---

Add this badge to your repository's README when your project uses BattleTest PR security reviews.

![Battletested! PR security reviews](/docs/badges/battletested.svg)

The badge identifies use of PR security reviews. It does not certify that a project is secure or that every change has been reviewed.

## Add it to your README

Copy this Markdown into your README:

```markdown
[![Battletested! PR security reviews](https://battletest.dev/docs/badges/battletested.svg)](https://battletest.dev/open-source?utm_source=readme&utm_medium=badge&utm_campaign=open_source)
```

Preview the README before committing. The image should show **Battletested! | PR security reviews**, and clicking it should open the open-source programme page. The descriptive image text also helps readers using assistive technology.

The badge is optional. It does not change your review limits, grant sponsorship, or affect any sponsored access. You can remove it whenever you want.

## Start reviewing pull requests

If you found BattleTest through a badge, [connect your GitHub repositories](/docs/how-to/connect-github) and follow [your first PR review](/docs/tutorials/quick-start). PR review is free within the [review limits](/docs/reference/limits-and-quotas).

For a deployment you operate yourself, start with [self-hosting](/docs/how-to/configure-source-control). The badge does not configure reviews or supply model credentials.
